When trying to signup with `pankaj@gmail.com`, the error "User with this email already exists" appeared.

### **✅ Solutions Available:**

#### **Option 1: Login Instead (Recommended)**
Since the email exists, try logging in:
1. Click **"Login"** instead of "Sign Up"
2. Use: **pankaj@gmail.com**

#### **Option 2: Use Different Email**
If you want to create a new account:

3. ✅ New account will be created

The system now helps you:
1. Try to signup with existing email
